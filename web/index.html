Live data integrations

Provide your own API credentials to fetch Copernicus Marine forecasts, real flight offers, and SNCF journeys alongside the distance-based heuristics. Keys are stored locally in this browser only.

Running the optional Node.js backend lets you keep credentials on the server instead. Configure them with COPERNICUS_USERNAME, COPERNICUS_PASSWORD, COPERNICUS_PRODUCT_ID, COPERNICUS_VARIABLES, RAPIDAPI_HOST, RAPIDAPI_KEY, and SNCF_TOKEN environment variables before starting the app.

Featured surf spots

Select a spot to reveal forecast details and travel cost estimates. Forecasts use the Copernicus Marine API when credentials are available, with an automatic Open-Meteo fallback.

Planning tips

  • Check the swell height and wind direction for the hours you plan to surf.
  • Use the price estimates to compare rail and flight options—they are based on average regional fares per kilometer.
  • Book flexible tickets and pack according to the temperature trends displayed for each location.
